# 钉钉助手 · 连接帮助（新人必读）

> 🆕 **推荐先看 [新人首配（OAuth 向导版）](./remote-新人首配-oauth.md)**：用 Quick 自带的 OAuth 向导自动授权，**不用复制粘贴 token、自动续期**。本文是「手动复制 Bearer」的备用流程，适用于 Quick 没有 OAuth 向导的情况。
>
> 面向**不懂技术**的同事。照着做就行，全程约 3 分钟，不需要任何代码或命令。
> 需要更详细的技术说明 / 故障排查矩阵，看 [remote-quick-desktop.md](./remote-quick-desktop.md)。

这是什么：在 Amazon Quick Desktop 里接上「钉钉助手」后，你就能用大白话让它**以你本人的身份**发钉钉消息、查群、查通讯录、建日程等——消息会用**你的头像和昵称**出现在群里，不是机器人。

向管理员要两样东西后再开始：

- **授权网址**：形如 `https://<域名>/authorize`
- **连接地址**：形如 `https://<域名>/mcp`（注意结尾是 `/mcp`）

---

## 一、第一次连接（3 步）

### 第 1 步：授权（用你自己的钉钉账号）

1. 用浏览器打开管理员给你的**授权网址** `https://<域名>/authorize`。
2. 页面会跳到钉钉，用**你自己的钉钉账号**点「同意」。
3. 钉钉跳回后，页面会显示一行以 `Bearer ` 开头的文字。**把这一整行复制下来**（这就是你的专属钥匙）。

> 这一步是为什么消息能「以你本人身份」发出去的关键——你是在用自己的账号授权。

### 第 2 步：填进 Amazon Quick Desktop

打开 **Quick Desktop → 设置（Settings）→ Capabilities → MCP → + Add MCP**，按下表填：

| 字段 | 填什么 |
|---|---|
| Connection type（连接类型） | 选 **Remote / HTTP** |
| Name（名称） | 随便起，比如 `钉钉助手` |
| URL（地址） | 管理员给的**连接地址**，例如 `https://<域名>/mcp`（务必以 `/mcp` 结尾） |
| Header（请求头） | `Authorization: Bearer ` 后面紧跟你第 1 步复制的那行 |
| Timeout (seconds) | 填 **300**（单位是秒，最大就是 300；这是「等待服务启动的最长时间」，填满即可） |

保存。状态应变成 **Connected ✅**，并显示一批可用工具（约 38 个）。

> 如果停在 "Configured" 没变 "Connected"：先检查 URL 是不是少了结尾的 `/mcp`，再检查 `Bearer ` 后面有没有完整粘上钥匙。仍不行就找管理员。

### 第 3 步：验证一下

在 Quick 对话框里输入：

```
用 dingtalk 查一下我自己的钉钉账号信息
```

如果返回的是**你本人**的企业、部门信息，就说明连通了。

## 二、它会一直能用吗？

**会。配一次就长期有效，平时不用管。**

后台会自动帮你的钉钉凭证续期，你粘进去的那行钥匙**只要你在用就一直有效**。唯一的例外：**连续 90 天完全没用过**，钥匙才会过期——这时按下面「三」重新连一次即可。正常使用的人基本永远不会遇到。

---

## 三、提示「连接失效 / 401」怎么办（重新连接）

极少数情况下（比如你 90 天没用过，或管理员重置了你的授权），Quick 会报连接失效。这**不是故障**，重新授权一次就好，步骤和第一次几乎一样：

1. 重新打开管理员给的**授权网址** `https://<域名>/authorize`。
2. 用你自己的钉钉账号点「同意」，**复制**返回的那行 `Bearer ...`。
3. 回到 **Quick Desktop → 设置 → MCP**，找到「钉钉助手」那一项，把 `Authorization` 里**旧的那行整个替换成刚复制的新的**，保存。

完成后再问一句「用 dingtalk 查我自己的资料」确认能用即可。换完之后又是长期有效。

## 四、常见问题

**Q：我的钥匙别人能用吗？需要保密吗？**
A：那行 `Bearer ...` 等于「以你身份操作钉钉」的钥匙，**当成密码对待**，别发群里、别截图外传。它只存在你自己电脑的 Quick 配置里。

**Q：我要去钉钉开发者后台配置什么吗？**
A：不需要。钉钉应用是管理员配的，你只是用自己的账号授权，全程只在浏览器点「同意」。

**Q：发消息会显示成机器人吗？**
A：不会。显示的是**你本人的头像和昵称**，就跟你自己打字发的一样。

**Q：换了电脑怎么办？**
A：在新电脑的 Quick 里按「一、第一次连接」重新走一遍即可（用同一个钉钉账号授权）。
